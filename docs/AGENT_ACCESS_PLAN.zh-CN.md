# 双开关与四模块 Agent 共享计划（A2）

日期：2026-11-13。依据用户本轮指令；本文件取代旧计划中便笺、图片、翻译可向 Agent 开放，以及使用时长只供人用的范围。H1 alpha.6 的已验收结果保留，不表示本轮功能已经实现。

## 产品规则

功能卡片保留“开启功能”，另增加“允许 Agent 访问”。后者是独立、持久化的用户授权；旧配置与新配置默认关闭。Agent 有效访问 = 模块支持 Agent × 功能已开启 × 用户已授权。关闭功能保留授权选择，但授权暂不生效；关闭 Agent 授权不关闭人的窗口、热键、采集设置或已有数据。重新开启功能恢复原授权，不擅自开启任何原来关闭的模块。

| 模块 | Agent 支持 | 共享范围与本轮最小有用能力 |
| --- | --- | --- |
| 截图 `screenshot` | 支持，需授权 | 显示器枚举、显式截图与可被模型读取的图像产物；与人的同一截图内核和产物空间协作 |
| 剪贴板 `clipboard` | 支持，需授权 | 同一历史库的有限查询、文本读取与显式文本写入；写入后人的候选窗可见，不自动粘贴进其他应用 |
| 屏幕注释 `screen_ink` | 支持，需授权 | 同一注释会话的状态、开关、穿透、结构化绘制、显式清空及快照；人和 Agent 看见同一画布 |
| 应用使用时长 `app_usage` | 支持，需授权 | 同一统计库的状态、日期范围概览、按应用与小时统计；查询不自动开启采样 |
| 便笺、图片/多媒体、置顶、脚本、翻译、密码本 | **不支持 Agent** | 保留完整人用功能；卡片明确“不支持 Agent”，不显示可授权开关，不开发这些模块的 Agent 适配 |

允许共享即复用用户选用模块的真实数据，不另建一份给 Agent 的虚假数据。开发测试使用可识别的生成数据和隔离目录；不为测试读取个人便笺、密码、日常剪贴板或历史统计。

## 实施顺序与分派

1. **A2.1 权限与界面先行。** Cursor 实现配置、静态支持目录、原生拒绝与人的授权命令；Antigravity 同时实现原功能卡片双开关。Codex 准备共享桌面服务接线与旧 Agent 导出的停用。先验收旧配置默认拒绝、授权持久化和原人用入口不受影响。
2. **A2.2 四模块适配。** Cursor 在同一 DesktopHost 内实现小而明确的 Agent 方法；Zed 按契约实现四类 Tool、动态注册、取消与图像结果。先交付权限框架和 JSON 读写能力，再补截图产物与真实注释绘制。高级截图的长截图、GIF、OCR不列为本轮 Agent 完成项，人的原功能继续保留。
3. **A2.3 Codex 集成与真实验收。** 按提交依赖集成，验证单一内核、UI/Agent 数据双向可见、四种开关组合、授权撤回和卸载；在已登录 Electron 使用生成数据完成模型调用。通过后才构建新版本并更新预览；不覆盖已冻结历史包。

## 集成门槛

- 新旧配置均不默认授权；四模块授权互不串用；不支持模块即使被手工配置为 true 仍拒绝。参数不能伪造人用身份或切换到任意 IPC。
- 四模块各验证启用/授权的四种组合、重启持久化和失败回滚。撤回后旧 Tool 引用也不能继续访问；读结果发布前重新检查，长任务在安全取消点停止。
- 人用操作不需要开启 Agent 授权；人的原快捷键、窗口、托盘、保存、采集开关继续按 H2 对等验收。开启/关闭采集模块后后台监听器必须同步启停，不能等重启才生效，也不能重复启动。
- Agent 不能自我授权、启用模块、导出全量配置、走旧便笺/图片入口或启动第二内核。历史 alpha.2 归档保持原样，新发布的所有导出/patch 都遵守新范围。
- 截图/注释需返回真实图像，不能用路径字符串冒充模型已能看图；产物限于受控目录，大小受限，不能借路径读任意本地文件。图像读取与发布也要检查授权。
- 剪贴板和统计使用相同库、明确时间范围与数量上限；不把个人内容写入诊断日志。授权/状态轮询只传元数据。
- 自动测试与真实 GUI、键盘、模型证据分别记录。未实现或未验证的高级能力明确报告，不以模拟成功替代。

## 后续仍保留的主线

A2 不取代 H2 十模块人用功能与原键位逐项验收、H3 配置/个人数据迁移、H5 发布兼容性验收。六个人用专属模块不因没有 Tool 而被视为迁移缺失。本轮先封闭权限边界和四模块最小有用共享，再逐项扩展这四项经验证的动作，不扩大支持模块名单。
