# 人用优先：桌面体验与快捷键迁移实施计划

日期：2026-11-13。依据用户最新澄清：插件主要给人使用，优先原有使用体验与快捷键，然后才做值得开放给 Agent 的功能。本文件与修订后的 MIGRATION_PLAN 是后续实施依据；早期“工具先行”的任务书与验收记录保留为历史。

## 1. 产品定义与已有成果

使用者不需要发消息给模型，就能从 Harness 打开工具箱，使用原来的“功能／偏好设置”、独立功能面板、原生浮窗、托盘和全局快捷键。迁移完成首先指人的日常操作完成；某项能力不注册为 Tool，并不影响它作为人的功能交付。

现有 `0.1.0-alpha.2` 是已验证的后端与接入基础：Named Pipe、进程所有权、便笺事务、图片转码、参数校验、取消和安装升级卸载。它没有迁移桌面界面与系统快捷键，不能作为完整人用 MVP 或旧工具箱替代品。原有测试结果保留，后续用于底层回归。

计划修订阶段未启动桌面程序或修改已冻结 alpha 包。用户随后已授权 H0/H1 实施，最新派工与真实进展见 [H1 派工记录](H1_COORDINATION.zh-CN.md)；原个人数据与日常 Profile 继续保持隔离。

H1 集成完成：当前 alpha.6 已在真实 Web 与已登录 Electron 通过可见入口、原主窗、便笺保存重开/重启、临时 OS 全局键、冲突/默认/Esc/Tab、装卸与模型共存验收，311 项自动测试通过。详情见 [H1 验收](INTEGRATION_H1.zh-CN.md)。这是人用纵向预览，H2 十模块逐项 GUI/原默认键实测与 H3 个人数据导入尚未完成。

## 2. 运行和入口方案

1. **可见且不经过模型的 Harness 入口。** H0 核对已安装版本的外部 Client/菜单/命令扩展，实际安装并点击验证，不凭指南假定某个 API 存在。若不支持，记录具体阻碍；CLI 能启动不能当作人的插件入口已完成。
2. **先复用 Tauri/Vue 桌面界面。** 原 `src-ui/src/App.vue` 已装配 Dashboard、FeaturePanel、便笺、截图遮罩、贴图、注释工具栏、翻译气泡和剪贴板候选窗。先把这些真实页面及 IPC 接回伴随宿主，尽量保持布局和操作习惯。完整改写为 Harness 内嵌页面不是恢复体验的前提。
3. **一个实例拥有一个内核和数据目录。** 不能同时运行 GUI 和 headless 两套内核写同一数据库。人的界面和选用的 Agent 适配复用一个受控运行实例；保留 headless 模式做独立后端测试不代表它拥有桌面能力。
4. **生命周期属于工具箱插件，而非一条聊天。** 关闭聊天不撤销快捷键；关闭主界面保留原托盘行为；关闭普通面板不等于关闭模块。密码本关闭锁定等原有特殊行为保留。显式退出、真正卸载或宿主运行时退出时，才按顺序保存、锁定、恢复窗口状态并释放所属资源。
5. **人的入口与 Agent 白名单分开。** 原生 WebView、Harness Client 与 Agent 调用各走已验证的入口和身份校验；不能让调用参数自行声称“来自人”获得权限。核心模块的启停与业务实现复用，不通过 LLM Tool 转发人的按钮操作。

Host 的人用运行服务已独立于 `tools` 服务装配；当前 alpha.6 默认 GUI Bundle 不注册 Agent 工具。A2 将仅为获授权的四项装配工具，并停用新版本中的旧便笺/图片 Agent 导出，不能以旧 headless patch 绕过新规则；历史归档保留。两种内核不能同时使用同一数据目录。

## 3. 原快捷键对等基线

依据固定源码的 USER_GUIDE、各模块 `ShortcutSpec`、`src-tauri/src/preferences.rs` 和真实注册路径核对。旧 handoff/早期测试文档里有历史组合键，不能用它们覆盖当前默认值。以下是源码快照的 Windows 默认绑定，**实际迁移优先保留用户自定义覆盖**；本轮没有读取个人配置。

本次只读核对原 C 盘项目 HEAD，仍为导出基线 `575075139fddc8b96d8db1a313c2fe404959c108`；没有复制新目录、访问个人数据库或更改原项目。

| 动作 | 源码默认绑定 | 对等要求 |
| --- | --- | --- |
| 截图 `screenshot:capture` | Ctrl+Alt+A | 外部应用前台可触发原遮罩；保留录制时再次触发的结束语义 |
| 长截图、GIF、OCR | 未设置 | 保留动作与可配置性，不擅自分配 F1 等历史默认值 |
| 剪贴板候选窗 `clipboard:toggle_popup` | Ctrl+Alt+D | 呼出/关闭、上下键、Enter、Escape、目标焦点恢复 |
| 注释 `screen_ink:toggle_session` | Ctrl+Alt+Shift+B | 开始/结束原画布与工具栏 |
| 注释穿透 `screen_ink:toggle_passthrough` | Ctrl+Alt+Shift+S | 绘制与操作下层应用切换 |
| 新建便笺 `sticky_note:create` | 未设置 | 保留可自定义及真实桌面便笺动作 |
| 选区翻译 `translator:translate_selection` | Ctrl+Alt+Shift+T | 选区获取、原应用焦点与翻译气泡行为 |
| 当前窗口置顶 `window_pin:toggle_foreground` | Ctrl+Alt+Shift+C | 切换置顶并正确恢复 |
| 准星拾取 `window_pin:pick_cursor` | Ctrl+Alt+Shift+W | 原拾取体验及取消 |
| 密码本 `password_vault:open_panel` | Ctrl+Alt+E | 打开原密码本及原认证流程 |
| 其他 `<module>:open_panel` | 未设置 | 每模块可设置/清除；重复打开前置已有面板 |
| 单个脚本热键 | 用户逐脚本设置 | 原脚本面板编辑、持久化、冲突与失败回滚 |

还需列全窗口内局部键：如截图编辑、便笺编辑、候选列表、对话框及快捷键录入。不能只迁上表的全局键。

快捷键的验收包含：

- 按原 action ID 保留逻辑绑定、Windows 实际组合键、未设置状态及持久化覆盖；默认值不能冲掉用户配置。
- 保留录入、Escape 放弃、Tab 导航、清除和恢复默认；已注册的组合键也能在聚焦的录入控件里正常记录。
- 保留内部重复检测、系统注册结果、清晰的冲突提示；失败不丢原绑定、不静默改键、不接管旧应用或其他程序的绑定。
- 模块关闭可编辑配置，但不注册该模块动作；重新开启恢复注册，卸载后释放。
- 在其他应用前台实际按键验证。调用 `kernel_trigger_shortcut`、点击按钮或检查注册表只算辅助证据，不能等同于热键实际生效。
- 开发用隔离配置和临时测试绑定，真实个人绑定导入属于后续用户数据迁移。无法自动验证的物理键项目明确留给人工，不写“已通过”。

## 4. 人用完成与 Agent 开放分别记录

| 功能 | 人用验收重点 | 当前 Agent 范围 |
| --- | --- | --- |
| 便笺 | 完整窗口、Markdown/LaTeX、编辑、置顶、关闭冲刷、重启 | **不支持 Agent**；新版本退役旧工具入口 |
| 图片/多媒体 | 原文件选择、批量队列、进度、取消、输出、FFmpeg | **不支持 Agent**；新版本退役旧工具入口 |
| 截图/贴图 | 原热键、区域/长截图/GIF/OCR、编辑、复制保存、贴图 | **支持独立授权**：先显式截图与真实图像产物 |
| 翻译 | 原面板、选区/划词、气泡、设置与凭据 | **不支持 Agent** |
| 屏幕注释 | 原画布、工具栏、穿透、状态恢复 | **支持独立授权**：共享原画布、绘制与快照 |
| 窗口置顶 | 原准星、置顶与状态恢复 | **不支持 Agent** |
| 剪贴板 | 原候选窗、搜索/固定/删除/粘贴、焦点与采集开关 | **支持独立授权**：共享历史文本查询与显式写入 |
| 脚本运行 | 配置/运行、参数、解释器、日志、超时取消、托盘和单脚本热键 | **不支持 Agent** |
| 密码管理 | 原面板、认证、条目/OTP、复制、锁定、导入恢复 | **不支持 Agent** |
| 屏幕使用时间/应用统计 | 用户开启后采样、统计面板、空闲/锁屏/睡眠与持久化 | **支持独立授权**：共享统计，只读查询不启用采样 |

人的功能启用开关与“允许 Agent 访问”是两个独立设置，授权默认关闭。仅上表四项支持，其他六项明确不支持；关闭授权不影响人用。关闭模块保留授权选择但暂不生效。最新实施范围见 [A2 计划](AGENT_ACCESS_PLAN.zh-CN.md)，其规定优先于历史任务。

## 5. 下一阶段的顺序与交付门槛

### H0：入口与对等清单

核实当前宿主可见入口；形成十模块的“原界面/原动作/全局键/局部键/配置/数据/已验证状态”矩阵。确认 Tauri/Vue 打包资源、WebView 用户数据和 GUI 正式启动参数都落在 D 盘项目内；现有 GUI QA 变量不当成产品接口。明确唯一进程与内核所有者，再安排实现。

### H1：首个人用闭环

交付路径为 **从 Harness 点击工具箱 → 原功能/偏好界面 → 新建并编辑桌面便笺 → 关闭/重开及重启保存 → 在偏好中录入面板快捷键 → 其他应用前台实按呼出 → 冲突/恢复默认 → 卸载释放**。

这个闭环全程不发模型请求，不以新建聊天为前提，不用空页面或只有状态的按钮代替原功能。现有 Agent 目录不在本阶段扩展。H1 是人用 MVP；其余模块尚未验证时明确列出，不能宣称整个旧应用已替代。

### H2/H3：原功能恢复、配置及数据迁移

按模块恢复原功能面板、桌面操作、完整快捷键和配置；脚本、密码本、使用统计作为人的模块推进，不等待 Agent 映射。依源码逐项验证高级截图模式，不省略后视为完成。配置和数据导入随对应模块推进，优先保护自定义快捷键、主题/语言、模块设置与原件；真实凭据和 Windows Hello 路径需要本人参与认证验收。

### H4：可选 Agent 适配

用户已将这一阶段具体化为 A2：仅截图、剪贴板、屏幕注释、应用使用时长支持可选访问与数据共享，其他六项不支持。独立授权、执行端检查、同一内核/数据、结果与取消处理先行；人的入口、快捷键和原生窗口继续保留，不另造一套业务状态。

### H5：人的发布验收

从实际发布包安装，验证入口、点击、键盘、窗口、焦点、托盘、重启保存、升级保留绑定和卸载。UI/键盘证据与技术回归分开记录；92 项 Node 和 43 项 Rust 历史通过不能代替这些未完成的项目。达到约定功能对等与数据验证后才建议替换旧工具箱。
