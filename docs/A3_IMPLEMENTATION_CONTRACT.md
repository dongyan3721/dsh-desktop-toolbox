### Native artifact transfer (Cursor implements; Codex consumes)

`agent.artifacts.read` params exactly `{artifact_id:string,module_id:'screenshot'|'screen_ink',offset:uint,length:uint}`; length1..65536. Response exactly `{artifact_id,module_id,offset,total_bytes,mime_type:'image/png',width,height,revision,data_base64,eof}`. offset<=total_bytes; response decodes at most requested length; eof iff offset+decoded length==total_bytes. Empty data only at EOF. Native ledger/sidecar determines module, size, dimensions, grant epoch; user-supplied module must match. No path inputs or path outputs needed for transfer. Require current enabled/granted module on every chunk and unchanged artifact's grant epoch; revoke then regrant cannot resurrect an artifact. Unknown/restarted/expired artifacts fail. Cap16MiB/16M pixels, TTL15minutes, bounded total256MiB with pruning; no arbitrary file read, symlink/reparse escape or unbounded allocation. Artifact descriptor remains A2 shape (with optional module_id/revision), and real PNG metadata/length must match bytes. This internal method is a transport capability, not a generic model tool; Zed does not register it as an action. Native ready capabilities advertise it when implemented.

Codex supplies `toolboxArtifacts.read(descriptor,{signal})` and the existing toolboxDesktop methods; Zed's image reader seam stays. Reader never reads a descriptor path. Native returns truthful partial/committed results for late cancellation; do not replace committed writes with CANCELLED.

### Trusted original Vue handshake (Cursor + Antigravity)

Human Tauri IPC only, NEVER pipe/Agent commands:

- `toolbox_agent_ui_ready` args `{kind:'notes',note_id:string}` from label `sticky-note-<id>` (verify actual label mapping), or `{kind:'ink'}` from `screen-ink-canvas`. Returns `{session_id:string}` generated native-side and bound to that actual window/instance. Do not trust args actor/window_label.
- `toolbox_agent_ui_result` args `{kind:'notes'|'ink',request_id:string,session_id:string,operation:string,ok:boolean,result?:object,error?:string}`. Native verifies actual invoking WebView, current session/request/operation, single completion, bounded payload. Return `{acknowledged:boolean}`. Payloads cannot set permissions or dispatch arbitrary IPC. Error text in external results is generic, not raw content. Wrong window/session/late or duplicate reply must not commit work.

Native emits to the specific original window, never broadcast secrets:

1. `sticky://agent-command`: `{request_id,session_id,note_id,operation:'prepare'|'apply'|'release',record?,write_session_id?}`. Prepare freezes inputs, drains autosave, flushes dirty edits WITHOUT closing, then acknowledges. Native reads current DB and applies mandatory expected_updated_at CAS after prepare; conflicts do not overwrite. Apply carries committed canonical record and newly issued write session id to invalidate old autosaves; Vue updates existing editor and acknowledges. Release always unfreezes corresponding request on success/error/cancel/timeout; it never replays stale record. Native must guarantee release even if prior ack times out; frontend has bounded recovery/refetch without throwing away drafts. If DB committed but apply ack lost, report committed result with display sync pending, not a failed uncommitted update; reconcile safely before another write. Read also flushes open dirty editor; search returns persisted summaries and does not claim unsaved drafts. API limits and five note methods follow A2_CONTRACT. Human saves/Agent updates must share per-note serialization/version fence; no bypass via save_closed_content.
2. `screen-ink://agent-command`: `{request_id,session_id,operation:'draw'|'snapshot'|'clear',strokes?,canvas_bounds:{x,y,width,height,scale_factor}}`. Coordinates for agent strokes are virtual desktop PHYSICAL pixels (negative origins valid), transformed to the original canvas's logical drawing coordinates using native actual bounds/scale. Draw appends to original InkHistoryManager and acknowledges `{applied:number}` after render. Clear uses same history and acknowledges completion. Snapshot redraws current ink and returns `{png_base64:string,width:uint,height:uint}` from original canvas; native validates PNG before controlled artifact creation. It is transparent canvas ink, no implicit unrelated desktop capture. Bounds/PNG caps apply before decoding/allocation. Pointer-stroke-active => BUSY instead of dropping user's stroke. Existing toolbar undo/redo, native clear/passthrough and human shortcut behavior stay consistent. Agent draw/snapshot advertised only when implementation exists; calls with no ready active session return UNAVAILABLE, not synthetic success.

Do not wait for frontend ack on Tauri main/UI thread, under a kernel/DB lock, or while blocking the event loop that must accept ack. Existing pipe request cancellation must be handled while waiting; native emit/state work may marshal to main briefly, waiting runs off it. Timeout <=5seconds per handshake, clean pending requests on shutdown/window loss/revoke/cancel. Add fake-coordinator tests for ack order/session ownership/timeout/late replies.
